# tsncd
![alt text](readme/transformer.png)

The TypeScript counterpart to [`pyncd`](https://github.com/mit-zardini-lab/pyncd). This package automatically generates diagrams from an algebraic description generated by `pyncd`. These packages communicate with each other using JSON and websockets, with the server hosted via either `pyncd`'s `run_server.py` or this package's `npm run server`. The data structure from `pyncd` is imitated in `data_structure`. The code is modularized, so that `display` contains `Render` (data structure/category theory/HTML independent), `Framework` (HTML independent), and finally `HTMLRender` (HTML dependent, data structure/category theory independent). This allows the code to be extended to different frameworks (e.g. React) in the future. The `Framework` code takes advantage of the categorical structure. For example, multiline expressions are rendered so that $F$ is rendered as lines $F_0$ and $F_1$ so that $F_0; F_1 = F$.

The wire format between the two packages is documented in
[`PROTOCOL.md`](PROTOCOL.md). `PROTOCOL.md` states every message, how a capture is
correlated, and the framing and font constraints that make images work. Change it
and both repositories have to move together.

Turning on `debugBorders` under `display/Render/RenderHandlerSettings.ts` shows the outlines of elements used to construct an expression.

## Choose the diagram theme

Diagrams use dark mode by default. Set `darkMode: false` in render settings to
use the light theme. Python theme arguments default to `None`, which omits
the setting and uses the renderer's default. `ColorMode.DARK` and
`ColorMode.LIGHT` select an explicit theme. Both themes share the same layout.

Dark block backgrounds use `blockBackground: 'subtle'` by default. Select `none`,
`medium` or `strong` to change their intensity. `blockHoverIntensity: 0.12` gives a
block and its associated BlockOperator the same hover tint.

```python
import websocket_transfer.websockets_transfer as wst
import websocket_transfer.send_morphism as sending

await sending.send_morphism(term, darkMode=wst.ColorMode.LIGHT)
```

The enum also works with `capture_morphism`, the headless renderer and notebook
`DiagramSettings.dark_mode`. Existing `True` and `False` calls remain supported.

Image exports use the diagram's background when `background` is omitted or
`"auto"`. Set a CSS color for an explicit background or `null` for transparency.

## Inspect the server's current diagram

Keep the relay and a diagram page running, then save the current diagram:

```bash
npm run capture -- --output tmp/current.png
npm run capture -- --output tmp/current-light.png --dark-mode false
npm run capture -- --output tmp/current.png --watch 2000
```

The command fetches the held term and requests an off-screen capture. Open the
PNG with an image viewer to inspect it. The visible diagram and the server's
held settings stay unchanged. Each poll completes before the next begins.
Stop polling with Ctrl+C. Use an `.svg` output path for SVG.

`--width 1400` overrides the preview's wrapping width. `--server` selects a
relay URL and `--timeout` sets the total timeout in milliseconds. Run
`npm run capture -- --help` for the options. Rebuild and reload the diagram
page after changing renderer code.

# Setup
(1) Download nvm for [MacOS/Linux](https://github.com/nvm-sh/nvm) or [Windows](https://github.com/coreybutler/nvm-windows).

(2) Then, we need to run;
```
nvm install --lts
nvm use --lts
npm install -g npm@latest
npm install
npm run dev
```
*This hosts a browser app. On refresh, the app connects to the relay server and renders whatever term the relay is holding, sent to it from `websockets_transfer.send_data(target)`.*

*Where the relay holds nothing, and where no relay is running, the page draws the figure the build carries: the quantised text-only DeepSeek-V4.1-Flash without the bodies of its blocks, with the legend of its axes and an inspection box over every block and every operator. The page fetches it from `json_files/deepseek_v41_flash_text_only_quantised.json`, which webpack writes into `dist/` from `public/`. [`PROTOCOL.md`](PROTOCOL.md) states it under "The figure a page boots with".*

*`npm run watch` runs the same dev server and also rebuilds `dist/` once edits have settled, so `pyncd`'s headless captures follow the working tree. It restarts the dev server when `webpack.config.js`, `tsconfig.json` or `package-lock.json` changes. `npm run watch -- --settle 10000` sets the settle period in milliseconds.*

(3) The relay server runs in a terminal of its own:
```
npm run server
```
*The relay sits between the notebook and the browser, because neither can dial the other. It holds the most recent term, so a refresh redraws the current diagram without the notebook running again. `pyncd`'s `python run_server.py` is the same relay and answers the same messages. Either will do. Only one of them may hold port 8765.*

## Displaying a model from pyncd

The model is built in `pyncd` and drawn here. `npm run build` writes `dist/`, which
`pyncd` reads for a headless capture and for a standalone HTML page. For a diagram in a
browser tab, the relay runs under `npm run server`, or under `pyncd`'s
`python run_server.py`, and the page is opened with `npm run dev`.

The `pyncd` notebook draws through `notebooks/display/notebook_diagrams.py`. Under
`INLINE` the figure is captured and embedded in the notebook cell, under `BROWSER` it is
sent to the open page, and under `HTML` it is written as one file that opens from the
disk with no server and no network. `pyncd`'s `notebooks/sota/DeepSeekV41Flash.ipynb` is
the worked example.

A figure may carry the legend of its axes, an inspection box over every block and every
expandable operator, and, in a page written under `HTML`, several wordings of its
descriptions with a control that switches between them.
